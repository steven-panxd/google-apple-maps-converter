Use it in your code

The converter is a small JavaScript library with no dependencies. It runs in Node, browsers, extensions and userscripts.

npm install google-apple-maps-converter
import { convert } from 'google-apple-maps-converter';

const { url } = await convert('https://maps.app.goo.gl/…');
// → https://maps.apple.com/place?coordinate=…&name=…

Questions

How do I convert an Apple Maps link to Google Maps?

Paste the maps.apple.com link above. The converter notices it is an Apple link and gives you a Google Maps link that works on Android, Windows and in any browser.

Why do Google Maps links open in Safari on my iPhone?

iOS opens google.com/maps links in the Google Maps app or in the browser. Converting the link to maps.apple.com makes it open in Apple Maps instead.

Can it open maps.app.goo.gl short links?

Yes, with the iPhone shortcut, which expands short links on your phone. On this page, open the short link in your browser first and paste the full address. Links that only carry a place ID, such as ?cid= links, have nothing to convert.

Do I need an app, an account or an API key?

No. It is a free web page and an optional shortcut. There is nothing to sign up for.

Is my link sent anywhere?

No. Links are converted in your browser and never leave your device. The map preview is loaded from OpenStreetMap.

Can I use it from my own app or shortcut?

Yes. Open this page with ?url= and the link, and add &go=1 to jump straight to the map. Or use the npm library above.
